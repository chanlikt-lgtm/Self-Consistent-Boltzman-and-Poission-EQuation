B

New blocker: the SHE contact Maxwellian had a spurious Z−1 — with n = ∫Zf0dε that does not give n = ncontact.

→ The audit is right — but it was a report typo, not a code bug. Corrected to f0 = ncontacte−ε/kT/∫Ze−ε/kTdε, and the bulk code was verified to already use the correct convention (she_bulk.py L66–68).

M1

The acoustic energy operator (the B1 fix) was under-specified — τac never given; provenance unclear.

→ Stated τac = τ1; derived the Fokker–Planck form (A = 4m*vs2ε/τac) from quasi-elastic acoustic energy transfer; and labelled it a reconstruction (my addition for irreducibility, not Liang’s treatment).

M2

Upper εmax boundary mischaracterized as a reflecting turning point — artificially retains hot carriers (biases impact ionization).

→ Separated the two limits: ε=0 is the physical band edge (reflecting); εmax is a numerical cutoff (absorbing). Validated by convergence: Te(300 kV/cm) = 3392.4 K identical at εmax = 3.02/4.0/5.0 eV.

m3

The Vth ≈ 0.6 V target (via NA~1.2×1017) was unsupported.

→ Tested and refuted by measurement: NA = 1.2×1017 gives Vth = 1.03 V, not 0.6. Reported as a measured Vth(NA) trend; 0.6 V needs a lower implant (≲6×1016), to be demonstrated in the recalibration.

m4

Production H-grid unspecified; Table-I transport parameters dropped in Rev 3.

→ Specified the H-grid: fixed global grid (no remapping), ΔH = 2.5 meV so Eop/ΔH = 20 is integer, from the a-priori bias envelope. Restored the full Table I (Dac, Dn, nscr, Dsa, …).

pass

Passes carried forward.

→ The auditor independently reproduced xj = 0.1707 µm and Id = 0.285 mA/µm, and passed both prior blockers (H-grid, zero-field Te), the band-model disclosure, and provenance.
